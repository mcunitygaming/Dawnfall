## Rules
1. Don't rename folders without discussing it.
2. Use existing templates for new concepts like Characters, Locations, and things like creatures (Unless there is no template, which in that case please create one P.S. this is optional).
3. Keep one concept per page.
4. Discuss major lore changes before editing shared systems (magic, angels, history, and bug events).
5. Commit with descriptive messages (e.g., "Added Halira backstory" instead of "Update").
